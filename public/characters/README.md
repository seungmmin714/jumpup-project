# 캐릭터 이미지

이 폴더의 PNG는 **손으로 넣지 않는다.** 원본을 `assets-source/characters/`에 두고
전처리 스크립트를 돌리면 여기에 표시용 파일이 만들어진다.

```bash
npm run prep:characters
```

| 파일명 | 식물 | plantId |
|---|---|---|
| `tomato-cherry.png` | 방울토마토 | `tomato-cherry` |
| `basil.png` | 바질 | `basil` |
| `lettuce.png` | 상추 | `lettuce` |
| `monstera.png` | 몬스테라 | `monstera` |
| `succulent.png` | 다육식물 | `succulent` |

> ⚠️ 파일명은 **`basil.png`처럼 이름만** 쓴다. 저장 대화상자에 `public/characters/basil.png`처럼
> 경로를 통째로 입력하면 macOS가 `/`를 `:`로 바꿔 `public:characters:basil.png`라는
> **한 개의 파일**을 만들어 버린다. 그러면 브라우저가 404를 받고 텍스트 표정으로 대체된다.

## 전처리가 하는 일

[`scripts/prep-characters.mjs`](../../scripts/prep-characters.mjs)

1. **배경 제거** — 테두리에서 배경색을 따라 들어가며 알파를 깎는다. 경계는 두 단계
   임계값으로 부드럽게 이어 붙여 계단 현상을 줄인다. 캐릭터 안쪽의 밝은 부분은
   테두리와 이어져 있지 않아 살아남는다.
2. **여백 트림 + 바닥 정렬** — 내용만 잘라 정사각 캔버스에 다시 얹되, 세로는 아래끝에
   맞춘다. 그래서 **캐릭터의 발이 항상 이미지 맨 아래**에 온다.
3. **표시용 축소** — 한 변 512px. 화면에서는 176px로 그려지므로 3배 화면까지 충분하다.

바닥 정렬이 중요한 이유: 홈 화면의 러그와 그림자는 캐릭터 박스의 아래끝을 바닥선으로
잡는다. 아트마다 발 높이가 제각각이면 어떤 식물은 러그 위에 뜨고 어떤 식물은 파묻힌다.

## 원본 규격

- **정사각형에 가까운 비율**이면 가장 좋고, 2:3 세로형까지는 그대로 처리된다.
- 배경은 **단색**이어야 한다. 그라데이션이나 무늬가 깔려 있으면 깨끗하게 안 지워진다.
  (투명 배경 PNG면 전처리가 트림·정렬만 하고 지나간다)
- 캐릭터 외곽선이 배경과 뚜렷하게 구분돼야 한다. 외곽이 흐릿하면 경계가 갉힐 수 있다.
- 크기는 클수록 좋다. 1024×1536 정도면 충분하다.
- `assets-source/`는 gitignore돼 있다. 커밋되는 건 축소본뿐이다.

배경이 잘 안 지워지면 스크립트 상단의 `T_TRANSPARENT`(기본 20) · `T_OPAQUE`(기본 62)를
조절한다. 배경이 남으면 값을 올리고, 캐릭터가 갉히면 내린다.

## 기분(mood) 표현

캐릭터 아트는 **식물당 한 장**이면 된다. 7종의 기분은 이미지를 갈아끼우는 대신
[`PlantCharacter.tsx`](../../src/features/character/PlantCharacter.tsx)가
색 필터·움직임·오버레이 아이콘을 얹어 표현한다.

| mood | 연출 |
|---|---|
| 0 OK | 은은하게 떠다님 + ✨🌿 |
| 1 THIRSTY | 채도를 낮추고 살짝 기울여 축 처지게 + 💧 |
| 2 HOT | 따뜻한 색조 + 떨림 + 💦🔥 |
| 3 COLD | 차가운 색조 + 떨림 + ❄️ |
| 4 DARK | 어둡게 + 💤 |
| 5 OVERWATER | 푸른 색조 + 흔들림 + 💧 |
| 6 SENSOR_ERR | 흑백 + 글리치 + ❓ |

기분별 전용 아트가 생기면 `src/data/plants.ts`의 `characterMoodImages`에 경로를 추가하면
그쪽이 우선 사용된다.

파일이 없으면 앱은 자동으로 텍스트 표정(`(◕‿◕)` 등)으로 대체하므로 화면은 깨지지 않는다.
